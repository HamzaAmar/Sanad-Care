## Purpose of This Document

This document defines **how an AI design / UX agent should understand, structure, and translate the Why‑Us content into a narrative-driven page experience**.

The page is **not a marketing page**.
It is a **story**.

Each section represents **one chapter** in a continuous journey, emotionally and cognitively guiding the user from *origin → insight → system → responsibility → promise*.

The design agent must prioritize:

* Storytelling over decoration
* Meaning over density
* Emotional clarity over visual noise

---

## Global Page Principles (Non‑Negotiable)

### 1. Story Flow

* The page must be read **top to bottom like a story**
* No section should feel independent or skippable
* Transitions must feel intentional, calm, and respectful

### 2. Section Structure

* **Each section = minimum 100vh**
* One idea per section
* One emotional takeaway per section

### 3. Visual Rhythm

* Alternating layout is allowed, but **consistency beats creativity**
* Text and visuals must never compete
* White space is a design tool, not empty space

### 4. Motion Philosophy (GSAP)

* Motion must feel:

  * Calm
  * Purposeful
  * Reassuring
* No aggressive or playful animations
* Animation supports meaning, not attention

---

## Global Animation Rules (GSAP)

For **every section**, apply the following animation logic:

### Trigger

* Animation triggers **when section enters viewport (60–70%)**

### Text Animation

* Origin: **Left (-X axis)**
* Opacity: 0 → 1
* Ease: `power3.out`
* Duration: 0.8 – 1.1s
* Stagger paragraphs slightly (0.15–0.25s)

### Visual / Design Element Animation

* Origin: **Right (+X axis)**
* Opacity: 0 → 1
* Scale: 0.95 → 1
* Additional effect: **soft bubble / expand effect**
* Ease: `expo.out`
* Duration: 1.1 – 1.3s

### Synchronization

* Text always appears **first**
* Visual follows with a **small delay (0.2–0.4s)**
